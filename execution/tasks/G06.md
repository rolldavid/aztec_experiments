## Acceptance

- **G06-A01** — Canonical parent/root, immutable posts, named and Anonymous identity, quotes/reposts and private duplicate-resistant likes.
- **G06-A02** — 992 UTF8 bytes enforced before spending; removed-parent navigation hides text; no reusable anonymous author identifier.
- **G06-A03** — Canonical reply parent/root; immutable author posts; moderation tombstones preserve navigation without text
- **G06-A04** — 992-byte UTF8 limit, character-oriented allowance, no silent truncation; safe URLs/labelled links and markup
- **G06-A05** — Authenticated onchain likes, quotes and reposts with canonical events sufficient for derived ranking and downstream delivery. Encrypted bookmarks/follows/notifications and complete UI are mandatory complementary G07-A03 and G09-A08 components.
- **G06-A06** — Composer lists own names plus exactly Anonymous; authenticate names without public owner grouping or reusable anonymous ID
- **G06-A07** — Human unlinkability across anonymous/named social transactions and private reactions, including backend/node traces and allowed prover witness trust. Identity/workspace components remain G05-A11/G10-A03; G13-A03 verifies the complete cross-application requirement.
- **G06-A08** — One active like/account/post across names, unlike; normalized case-insensitive full names immutable/reserved bots with specified Unicode bounds
