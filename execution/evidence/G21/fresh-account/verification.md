# Same-wallet fresh test accounts

An explicit Start new test account action is available on Sepolia/local test networks. It opens wallet selection immediately and skips automatic restoration for that attempt. A valid Ethereum signature derives a separate deterministic numbered Aztec identity. The generation comes from the configured collateral portal depositNonces(owner)+1, so a completed aggregate signup advances the next test identity even after browser data deletion. Before payment, repeating setup deliberately selects the same unfunded generation. Existing same-owner portal support is reused; no contract deployment or service restart is needed.

The selected public generation and encrypted session commit in one IndexedDB transaction only after signature verification. Normal return restores automatically; sign-out keeps the selected generation for subsequent wallet sign-in. A cancelled signature retains the previous session/selection. Clearing browser data loses remembered selection, but Start new test account still selects a generation after the portal's latest successful signup. This is an explicit test feature, not an on-chain deletion or a change to normal account derivation.
